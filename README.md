# Firebase Database Practice

React product management component backed by a Firebase integration.

## Project structure

- `src/components/ProductManagement.jsx`
- `src/firebase.js`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/firebase-db-project.git
cd firebase-db-project
```

Configure a local test Firebase project and restrictive database rules.

Install Node.js and npm, then run `npm install` and `npm run dev` in the application directory. Open the terminal URL.
